About this project

This portfolio prototype demonstrates a human-in-the-loop workflow for evaluating AI-generated responses. Reviewers manually score Accuracy, Relevance, Clarity, Completeness and Safety, add evidence-based notes, and make a Pass / Needs Review / Fail decision.

Technology: HTML, CSS and vanilla JavaScript. Review history is stored locally in the browser; no paid API or server is required.

Important: This prototype does not claim to independently fact-check responses. It is designed to demonstrate structured review and QA skills.
