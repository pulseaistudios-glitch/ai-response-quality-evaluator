# AI Response Quality Evaluator

A lightweight portfolio prototype for evaluating AI-generated responses across:
- Accuracy
- Relevance
- Clarity
- Safety
- Overall quality

## How it was built
HTML, CSS and vanilla JavaScript. The interface was designed to demonstrate a practical AI evaluation/quality-assurance workflow.

## Portfolio use
This project demonstrates skills relevant to AI data annotation, response evaluation, linguistic quality review, and structured QA.
